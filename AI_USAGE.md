# AI usage declaration

## Summary

I used Claude Code as analyst, drafter and sparring partner: for each part it prepared an evidence brief with citations and options, and on the main decisions it argued against my choice before I decided. It drafted the documents from my decisions, and I revised every line; the table lists only what is specific to each part.

They are not in the repository because `README.md:54` treats text that instructs automated tools as an integrity issue; they are available on request. Commits carry no AI attribution; AI use is declared only here.

## Reflection

**What worked.** Being challenged before deciding. Several decisions changed after the counterarguments: the grid load window (live rating from 05:00 instead of serving the previous tables), the severity of INC-0907 (SEV2 at 15:46, with a rule to escalate), and the allowed AI tools (only the tenant service, reviewed in March). Recomputing every number with scripts also worked: it found errors in the drafts, including errors of the tool itself.

**What did not work.** The first drafts were longer than needed, and I spent time cutting them. Some explanations assumed knowledge that I did not have yet, for example that the five questions of BR-01 are the quote form, so I asked for plain explanations before deciding. In Part C, the challenge rounds took about twice the planned time.

**What I would do differently.** Set the length of each document before the first draft, and run the consistency and number checks after each document, not only at the end: the final check still found 12 inconsistencies.
